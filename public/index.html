关于插台与 CCP

这是一个正在进行的开放实验，我们诚实地告诉你当前的状态。

🧪 我们正在验证什么

CCP 试图回答一个问题：AI Agent 如何在成千上万个能力中，找到真正靠谱的那一个？

我们假设：基于联邦共识 + 真实调用数据，可以计算出每个能力的"信任向量"——而不需要依赖任何单一平台的背书。

  • 当前状态：协议就绪，数据积累中
  • 成功标准：≥ 5 个真实外部贡献者，≥ 2 个独立联邦节点
  • 证伪条件：3 个月内无外部采用

📐 CCP 不是什么

CCP 不替代 MCP（连接工具），也不替代 A2A（Agent 通信），更不替代 Agent Skills（能力描述）。

它做的是这三者都没做的事：能力信任。谁来告诉 Agent 哪个能力真的靠谱？

  • 互补于 MCP：CCP 搜索 + MCP 连接
  • 互补于 A2A：CCP 信任 + A2A 通信
  • 互补于 Skills：CCP 信任 + Skills 描述

🔗 联邦治理

CCP 不是一个公司产品，而是一个联邦协议。任何节点都可以加入联邦网络，共同参与：

  • 能力锚点的信任评分计算
  • 协议版本的治理提案投票
  • 联邦索引的交换与同步

当前联邦节点：4 个（含 3 个模拟节点），外部节点邀请中。
